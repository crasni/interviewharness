# Naming: decided **InterviewHarness** (2026-10-29)

## Why
- **Intuitive.** The user insisted the name say what it does. No metaphors, no character names.
- **Unique.** No GitHub repos used the name when checked (only a 1★ `interview-harness`). Free on npm. `interviewharness.dev` and `.ai` showed no DNS records, so they're probably unregistered; **confirm at a registrar.** `.com` is registered by someone else.
- **Fits the 2026 "-Harness" trend** (agent-harness engineering): deepseek-harness (265k★), browser-harness (19k), OpenHarness (16k), phone-harness, QuantHarness, LearnHarness (3.5k). Developers read "XHarness" as "an agent app for X".

## Known downsides (accepted)
- "Harness" may date as a fad, and it means little to non-developers.
- "Harness" is also Harness Inc.'s name (harness/harness, 39k★, a DevOps company). Compound names are widely used, so the risk is low but nonzero.

## Rejected
- **OpenInterview:** a 248★ repo with the same name, a near-identical voice interview project (OmnAILab), and a cheating tool `openinterviewcoder`; `.com` is parked.
- **MockLoop:** a MockLoop org/MCP already exists; domains registered.
- **Cute or metaphorical:** Mmhm, Quietroom, Tacet, Sparring, Dry Run, Rook/Vale/Moss. The user rejected these as not intuitive.
- **Crowded:** MockMate (932 repos), InterviewCoach (180), InterviewBuddy (149), InterviewSim (109), InterviewKit, InterviewForge.
- **Other clean runners-up:** MockOnsite (0 repos, .dev free), InterviewGym, InterviewBench, MockHarness, PrepHarness.
