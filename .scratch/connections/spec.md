# Connections: every way to bring a model

Status: ready-for-agent

Decisions: ADR 0021. Research: `docs/research/13-keys-and-plans.md` (and `12-model-picker-patterns.md` for layout).

Settings → Model keeps its shape (the two model slots, then Connections). What changes is adding a connection: a searchable list grouped by kind, with many more sources, several custom servers, OpenRouter sign-in, and plain reasons for plans the app can't use. The Start screen's API key row opens the same list. Every add still ends in the one-short-reply check, keys still live only in the OS credential store, and the screens stay full height with their own scroll.
